# ✅ To-Do список

Красивое и простое браузерное приложение для управления задачами. Проект отлично подходит, чтобы потренироваться работать с данными в JavaScript, обновлять интерфейс без перезагрузки страницы и сохранять состояние в `localStorage`.

## ✨ Что умеет приложение

- ➕ **Добавлять задачи** — введите текст и нажмите кнопку «Добавить».
- ✅ **Отмечать выполненные** — кликайте по чекбоксу рядом с задачей.
- 🗑️ **Удалять лишнее** — убирайте отдельные задачи одной кнопкой.
- 🧹 **Очищать выполненные** — быстро удаляйте все завершённые задачи.
- 💾 **Сохранять список** — задачи остаются на месте после обновления страницы благодаря `localStorage`.
- 📊 **Показывать статистику** — видно общее количество задач и число выполненных.
- 📱 **Работать на разных экранах** — интерфейс адаптируется под мобильные устройства.

## 🧠 Почему это полезный проект

Этот To-Do список помогает разобраться с базовыми, но важными темами фронтенда:

- 🧩 работа с DOM-элементами;
- 📝 обработка событий формы, кнопок и чекбоксов;
- 🔄 обновление данных и повторная отрисовка списка;
- 🗃️ хранение данных в браузере;
- 🎨 стилизация интерфейса через CSS;
- ♿ базовая доступность с `label`, `aria-live` и понятными кнопками.

## 🚀 Быстрый старт

Можно просто открыть файл `index.html` в браузере. Если хочется запустить проект через локальный сервер, используйте команду:

```bash
python3 -m http.server 4173
```

После запуска откройте в браузере:

```text
http://127.0.0.1:4173
```
