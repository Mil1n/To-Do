# ✅ To-Do список

Красивое браузерное приложение для управления задачами: добавляйте дела, отмечайте прогресс, редактируйте карточки, сортируйте список и храните данные прямо в браузере через `localStorage`.

## ✨ Что умеет приложение

- ➕ **Добавлять задачи** с категорией, приоритетом и дедлайном.
- ✅ **Отмечать выполненные** задачи одним кликом.
- ✏️ **Редактировать** название, категорию, приоритет и срок.
- 🗑️ **Удалять задачи** с возможностью отменить удаление.
- 🧹 **Очищать выполненные** задачи одной кнопкой.
- 🔍 **Фильтровать** список: все, активные и выполненные.
- ↕️ **Сортировать** задачи по дате создания, приоритету или дедлайну.
- 📊 **Следить за прогрессом** через счётчики и прогресс-бар.
- 🌙 **Переключать тему** между светлым и тёмным режимом.
- 💾 **Сохранять состояние** в `localStorage`.
- 📦 **Экспортировать и импортировать JSON-файл** со списком задач.
- 📱 **Запускаться как PWA** благодаря manifest-файлу и service worker.
- ⌨️ **Использовать горячие клавиши**: `/` фокусирует поле ввода, `Escape` очищает его.

## 🧠 Почему это полезный проект

Этот To-Do список помогает разобраться с важными темами фронтенда:

- 🧩 работа с DOM-элементами;
- 📝 обработка событий формы, кнопок, чекбоксов, dialog и file input;
- 🔄 фильтрация, сортировка и повторная отрисовка данных;
- 🗃️ хранение данных в браузере;
- 📁 экспорт и импорт файлов;
- 🧪 базовое тестирование бизнес-логики;
- 🎨 стилизация интерфейса через CSS-переменные;
- ♿ доступность с `label`, `aria-live`, `aria-pressed` и понятными кнопками;
- 📲 основы PWA: `manifest.webmanifest` и `service-worker.js`.

## 🚀 Быстрый старт

Можно просто открыть файл `index.html` в браузере. Для PWA-возможностей лучше запустить локальный сервер:

```bash
python3 -m http.server 4173
```

После запуска откройте в браузере:

```text
http://127.0.0.1:4173
```

## 🧪 Проверки

```bash
node --check main.js
node --check render.js
node --check storage.js
node --check tasks.js
node --test test/tasks.test.mjs
```

## 🗂️ Структура проекта

```text
.
├── index.html             # 🧱 Разметка приложения
├── styles.css             # 🎨 Внешний вид, адаптивность и темы
├── main.js                # ⚙️ События и состояние приложения
├── render.js              # 🖼️ Отрисовка интерфейса
├── storage.js             # 💾 localStorage, импорт и экспорт
├── tasks.js               # 🧠 Бизнес-логика задач
├── service-worker.js      # 📲 PWA-кеширование
├── manifest.webmanifest   # 📱 Метаданные PWA
├── icon.svg               # ✅ Иконка приложения
└── test/tasks.test.mjs    # 🧪 Тесты логики задач
```
