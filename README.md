# To-Do список

Небольшое браузерное приложение для работы со списком задач. Оно помогает потренироваться с данными в JavaScript и сохранением состояния в `localStorage`.

## Возможности

- Добавление новой задачи.
- Удаление отдельной задачи.
- Отметка задачи как выполненной.
- Массовое удаление выполненных задач.
- Автоматическое сохранение списка задач в `localStorage` браузера.

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python3 -m http.server 4173
```

После этого приложение будет доступно по адресу <http://127.0.0.1:4173>.
