# ✅ To-Do список

Красивое браузерное приложение для управления задачами: добавляйте дела, отмечайте прогресс, редактируйте карточки, сортируйте список, работайте офлайн и храните данные прямо в браузере через `localStorage`.

## ✨ Что умеет приложение

- ➕ **Добавлять задачи** с категорией, приоритетом, дедлайном и повтором.
- ✅ **Отмечать выполненные** задачи одним кликом.
- 🔁 **Создавать повторяющиеся задачи**: ежедневно, еженедельно или ежемесячно.
- ✏️ **Редактировать** название, категорию, приоритет, срок и повтор.
- 🗑️ **Удалять задачи** с возможностью отменить действие.
- 🧹 **Очищать выполненные** задачи одной кнопкой.
- 🔍 **Искать и фильтровать** список: все, активные и выполненные.
- ↕️ **Сортировать** задачи вручную, по дате создания, приоритету или дедлайну.
- 🧭 **Перетаскивать задачи** drag-and-drop для ручного порядка.
- 🏷️ **Добавлять свои категории** без изменения кода.
- 🎨 **Настраивать акцентный цвет** интерфейса.
- 📊 **Следить за прогрессом** через счётчики, прогресс-бар и дашборд продуктивности.
- 🔔 **Видеть статусы дедлайнов**: сегодня, завтра, скоро или просрочено.
- 🌙 **Переключать тему** между светлым и тёмным режимом.
- 💾 **Сохранять состояние** в `localStorage`.
- 📦 **Экспортировать и импортировать JSON-файл** со списком задач.
- 📱 **Запускаться как PWA** благодаря manifest-файлу и service worker.
- 📴 **Получать офлайн-статус** и продолжать пользоваться кешированным приложением.
- ⌨️ **Использовать горячие клавиши**: `/` фокусирует поле ввода, `Escape` очищает ввод и поиск, `Ctrl/Cmd+Z` отменяет последнее действие.

## 🧠 Почему это полезный проект

Этот To-Do список помогает разобраться с важными темами фронтенда:

- 🧩 работа с DOM-элементами;
- 📝 обработка событий формы, кнопок, чекбоксов, dialog, file input и drag-and-drop;
- 🔄 фильтрация, поиск, сортировка и повторная отрисовка данных;
- 🗃️ хранение задач, категорий, темы и акцентного цвета в браузере;
- 📁 экспорт и импорт файлов;
- 🧪 базовое тестирование бизнес-логики;
- 🎨 стилизация интерфейса через CSS-переменные;
- ♿ доступность с `label`, `aria-live`, `aria-pressed` и понятными кнопками;
- 📲 основы PWA: `manifest.webmanifest`, `service-worker.js`, кеширование и офлайн-индикатор.

## 🚀 Быстрый старт

Можно просто открыть файл `index.html` в браузере. Для PWA-возможностей лучше запустить локальный сервер:

```bash
python3 -m http.server 4173
```

После запуска откройте в браузере:

```text
http://127.0.0.1:4173
```

## 🧪 Проверки

```bash
node --check main.js
node --check render.js
node --check storage.js
node --check tasks.js
node --check service-worker.js
node --test test/tasks.test.mjs
```

## 🗂️ Структура проекта

```text
.
├── index.html             # 🧱 Разметка приложения
├── styles.css             # 🎨 Внешний вид, адаптивность, темы и dashboard
├── main.js                # ⚙️ События, состояние, undo, PWA и настройки
├── render.js              # 🖼️ Отрисовка интерфейса и продуктивности
├── storage.js             # 💾 localStorage, импорт, экспорт и настройки
├── tasks.js               # 🧠 Бизнес-логика задач
├── service-worker.js      # 📲 PWA-кеширование
├── manifest.webmanifest   # 📱 Метаданные PWA
├── icon.svg               # ✅ Иконка приложения
└── test/tasks.test.mjs    # 🧪 Тесты логики задач
```
